# Helenite 사용 안내

[English](USER-GUIDE.md)

**알파 사용 안내 · 2026년 10월 26일 갱신.** 최신 준비된 데스크톱 설치본은 0.1.9이며 플러그인 0.1.3이 포함되어 있습니다. 데스크톱과 플러그인의 버전 번호는 별개입니다. Helenite는 Egress의 독립 제품이며 Obsidian 공식 제품이 아닙니다. 일반 사용자용 데스크톱 다운로드·결제·커뮤니티 플러그인 등재는 아직 열리지 않았습니다. 별도 공개되는 플러그인 알파는 초대 시험과 심사용이며 공개 서비스 활성화를 뜻하지 않습니다. 아래에서 출시 후 경로와 현재 초대 시험 경로를 구분합니다. 최종 버전으로 일반 사용자가 도움 없이 처음부터 연결하는 실기기 검증은 아직 남아 있습니다.

## 준비할 것

- 컴퓨터와 휴대폰의 Obsidian, 각 기기에 보관함 사본을 저장할 충분한 공간.
- 서버로 사용할 컴퓨터 한 대. 그 컴퓨터에서 **Helenite 앱과 Helenite 플러그인이 켜진 Obsidian을 함께 실행**해야 합니다. 데스크톱 앱만으로 로컬 노트가 동기화되지는 않습니다.
- 별도 시험 보관함과 옮길 노트의 백업. 현재 시험에서는 같은 보관함에 iCloud·Obsidian Sync·다른 동기화 도구를 함께 사용하지 마세요.

휴대폰에서는 계속 Obsidian을 사용합니다. PC 폴더를 원격으로 여는 방식이 아니라, 노트를 휴대폰에도 내려받아 보관합니다. **실사용 동기화에 USB 케이블은 필요 없습니다.** 다른 네트워크에서도 쓰려면 외부 연결이 준비되어야 합니다. 현재는 시험 담당자의 초대가 필요하며, 앱 설치만으로 공개 서비스가 활성화되지는 않습니다.

## 1. 서버로 쓸 컴퓨터 준비

1. 지금은 초대 시험에서 받은 설치본을 사용하세요. 공개 배포 후에는 [helenite.net](https://helenite.net/)에서 내 컴퓨터에 맞는 파일을 받습니다.
2. Helenite를 설치하고 엽니다. 현재 후보는 **macOS Apple Silicon(ARM64)**, **Windows x64**, **Ubuntu 22.04 x64용 DEB**입니다. Intel Mac·Windows ARM·모든 Linux 배포판의 지원을 뜻하지 않습니다. Mac은 서명·공증, Linux는 패키지 서명을 마쳤습니다. Windows 서명은 준비 중이므로 현재 파일은 공개 출시본이 아닌 시험본입니다.
3. Obsidian에서 시험 보관함을 엽니다. Helenite에서 **내 보관함 찾기**로 같은 폴더를 선택하고 **Helenite 설치**를 누릅니다. 선택한 보관함에 플러그인을 추가하는 단계입니다. 데스크톱 앱을 설치하기만 하면 모든 보관함에 자동 설치되는 것은 아닙니다.
4. Obsidian의 **설정 → 커뮤니티 플러그인**에서 **Helenite — By Egress**를 확인하고 켭니다. 제공받은 플러그인을 확인한 뒤 커뮤니티 플러그인 실행을 허용하세요. 목록에 없으면 설치 목록을 새로고침하거나 Obsidian을 다시 열고, 선택했던 보관함인지 확인합니다.
5. Helenite가 실행 중인 플러그인을 확인하면 **다음으로 → 이 컴퓨터에서 시작 → 이 컴퓨터로 시작**을 누릅니다. 서버가 **실행 중(Running)**인지 확인하세요.

**연결 설정**에서 **창을 닫아도 실행 유지**, **로그인할 때 시작**을 켤 수 있습니다. 이는 Helenite의 실행 설정이며 Obsidian까지 자동으로 여는 기능은 아닙니다. 변경을 주고받을 때는 서버 보관함도 Obsidian에 열어 두세요. 백그라운드 실행 설정이 컴퓨터의 잠자기를 막아 주지는 않습니다.

## 2. 외부 연결 준비

**출시 후 공개 경로:** Helenite의 **브라우저에서 로그인**을 누르고, 브라우저에서 이메일 코드를 입력한 뒤 앱 연결을 승인합니다. 표시된 계정이 맞는지 확인하세요. 계정 화면에서 제공되는 **이 PC 등록**을 누릅니다. 등록에는 유효한 구독 자격이 필요하며 로그인만으로 중계 연결 권한이 생기지는 않습니다.

**현재 초대 시험:** 시험 담당자에게 받은 계정·연결 안내를 따릅니다. **PC 등록 서비스 준비 중**이면 공개 등록이 아직 닫힌 상태입니다. 서버 주소를 추측하거나, 구독을 다시 결제하거나, 개발용 설정을 바꿔 우회하지 마세요.

등록된 PC의 연결 자격은 자동 갱신됩니다. 일반적인 로그인 만료만으로 이메일 코드를 계속 입력할 필요는 없습니다. 이용 자격이 끝나거나 확인할 수 없으면 외부 전송은 멈추고 로컬 노트는 남습니다. 화면에 표시되는 계정·연결 조치를 따르세요.

## 3. 휴대폰의 Obsidian 준비

1. PC Helenite의 **휴대폰 연결**에 표시된 보관함 이름을 확인하세요. 휴대폰 Obsidian에 **정확히 같은 이름의 빈 로컬 보관함**을 만들어 엽니다. PC에 `내 연구노트`가 표시되면 휴대폰도 `내 연구노트`로 만듭니다. 같은 연결 보관함의 휴대폰 사본을 준비하는 단계이며, 여기에 PC의 노트가 내려옵니다. iPhone/iPad에서는 새 보관함의 **Store in iCloud(iCloud에 저장)**를 끄고, Android에서는 Obsidian이 사용할 수 있는 기기 저장소를 선택하세요.
2. **커뮤니티 등재 승인 후:** **설정 → 커뮤니티 플러그인 → 탐색(Browse)**에서 **Helenite**를 검색하고 **By Egress**를 확인한 뒤 **설치 → 활성화**합니다.
3. **승인 전인 지금:** 검색으로 Helenite를 받을 수 없습니다. 초대 시험에서 제공받은 보관함/플러그인 패키지와 기기별 설치 안내를 사용한 다음 해당 보관함에서 Helenite를 켭니다. 시험 패키지를 기존 개인 보관함에 덮어 풀지 마세요. 설치 안내를 받지 않았다면 여기서 시험 담당자에게 확인하세요.

Helenite를 사용할 보관함마다 플러그인을 설치하고 켜야 합니다. QR은 플러그인을 설치하거나 휴대폰 보관함을 만들어 여는 기능이 아닙니다. Obsidian의 **Set up Obsidian Sync**는 Obsidian 자체 서비스의 설정입니다.

**이미 다른 이름으로 연결했나요?** 그 보관함과 연결을 그대로 사용하세요. Obsidian의 보관함 관리에서 기존 휴대폰 보관함 이름만 PC에 표시된 이름으로 맞추면 됩니다. 같은 이름의 보관함이 이미 있으면 어느 보관함을 사용할지 먼저 확인하고 덮어쓰지 마세요. Helenite가 Obsidian 폴더 이름을 자동 변경하지는 않습니다. 이름만 같다고 연결되는 것은 아니며, 같은 보관함인지는 기존 승인 연결로 구분합니다. 이름을 맞추려고 파일이나 Helenite 설정을 지우거나 새로 연결할 필요는 없습니다.

## 4. QR 또는 복사한 코드로 연결

1. PC에서 외부 연결이 준비된 뒤 **휴대폰 연결**을 선택해 새 연결 코드를 만듭니다. 화면을 유지하고 만료 시간을 확인하세요.
2. 휴대폰에서 이름을 맞춘 로컬 보관함을 열고 Helenite를 켠 상태로, 카메라로 PC의 QR을 읽어 Obsidian으로 엽니다.
3. 인식하거나 열지 못하면 PC의 **연결 링크 복사** 또는 코드 복사를 사용해 본인 휴대폰으로 비공개 전달하세요. Obsidian의 명령 팔레트에서 **Helenite: 동기화 화면 열기**를 실행하고 **받은 코드 붙여넣기**를 누릅니다. 또는 **직접 입력하기**에 코드/링크 전체를 붙여 넣고 **다음**을 누릅니다.
4. 대상 보관함과 이름을 확인합니다. 파일이 이미 있으면 기존 파일도 동기화할지 묻습니다. 그 파일까지 포함하려는 경우가 아니라면 빈 시험 보관함을 사용하세요. **PC에 연결 요청**을 누릅니다.
5. 두 기기의 확인 문구를 비교하고, **같을 때만** PC에서 해당 휴대폰을 승인합니다. 기기 이름만으로 판단하지 마세요. 최초 전송이 끝날 때까지 휴대폰의 Obsidian을 화면에 열어 둡니다.

연결 링크·코드는 비공개로 다루고 스크린샷이나 문의 글에 올리지 마세요. 만료되면 PC에서 새 코드를 만듭니다. **열린 연결 화면을 먼저 마쳐 주세요**가 나오면 기존 연결창으로 돌아가 완료하거나 닫은 후 다시 여세요. 반복 스캔하거나 연결 설정을 지우지 마세요.

최신 플러그인 후보로 동기화 보관함을 처음 만들 때 공통 이름을 기록합니다. 업데이트된 데스크톱 서버와 양쪽 기기의 플러그인을 사용하면, 이후 승인하는 새 기기에 이 이름도 암호화해서 전달합니다. Helenite에서는 이 이름을 표시하고, 각 기기에는 로컬 파일을 보관합니다. Obsidian 자체의 보관함 이름은 별도로 관리되므로 한 기기의 폴더 이름을 바꿔도 모든 기기에서 자동 변경되지는 않습니다. 공통 이름 없이 사용하던 기존 연결은 그대로 유지되며 로컬 이름을 표시합니다. 위 안내대로 이름만 맞추고 보관함을 지우거나 다시 연결하지 마세요. 이전 서버나 플러그인과도 연결할 수 있지만 이름은 전달되지 않을 수 있습니다.

## 5. 처음 동기화됐는지 확인

최초 연결에서는 지원되는 보관함 파일을 내려받습니다. 그다음부터 변경 사항을 전송하고 가능한 경우 암호화된 조각을 재사용합니다. 편집할 때마다 보관함 전체를 다시 내려받는 방식은 아닙니다.

1. PC와 휴대폰의 보관함을 열어 두고 **동기화 완료**를 기다립니다. 보류 항목이나 충돌 사본이 있는지도 확인하세요.
2. PC에 임시 노트를 만들어 휴대폰에 나타나는지 확인합니다.
3. 휴대폰에서 다른 문장을 추가해 PC에도 반영되는지 확인합니다. 이 과정이 된 뒤 다른 기기를 추가하세요.

**연결됨**은 연결 준비 상태이며, 모든 파일 수신 완료를 뜻하지 않습니다. 실제 시험 노트와 **마지막 동기화**를 확인하세요. 최초 파일이 많으면 시간이 더 걸릴 수 있습니다. 숨김 파일과 `.obsidian` 설정·테마·플러그인은 제외되므로 노트 동기화로 기기 설정까지 복사되지는 않습니다.

## 평소 사용, 오프라인 편집과 잠자기

모바일에서는 동기화할 동안 **Obsidian을 화면 맨 앞에 열어 두세요.** 휴대폰을 잠그거나 다른 앱으로 이동하면 플러그인이 멈출 수 있습니다. 백그라운드 동기화를 보장하지 않습니다.

PC가 잠들거나 꺼지거나 인터넷이 끊겨도 휴대폰에 이미 있는 노트는 편집할 수 있습니다. 미전송 로컬 변경은 보존합니다. 다시 사용할 때 PC를 깨우고 네트워크를 연결한 뒤 같은 보관함을 열어 자동 재시도를 기다리세요. 오류와 서버 응답에 따라 재시도 대기가 달라지므로 고정된 몇 초 안의 반영을 보장하지 않습니다. 직접 일시정지했다면 **재개**를 누릅니다. 연결·자격 오류가 표시되면 안내된 조치를 따르세요.

전송이 늦는다는 이유로 보관함을 초기화하거나 플러그인 설정을 삭제하거나 새 연결을 반복해서 만들지 마세요. 저장된 상태는 안전한 재개에 필요합니다.

## 동시 수정, 삭제와 파일 복구

지원 크기 안의 Markdown 노트에서 서로 다른 부분을 바꾸면 자동으로 병합할 수 있습니다. 같은 부분의 수정은 항상 병합되지 않습니다. Helenite가 사본을 보존하고 검토를 기다립니다.

1. 동기화 화면이나 명령 팔레트에서 **변경 사항 검토**를 엽니다.
2. **이 기기의 파일**과 **다른 기기의 파일**을 비교합니다. **이 버전 유지**, **다른 버전 사용**, 또는 가능한 경우 **직접 병합 → 병합한 내용 사용**을 선택합니다.
3. 확인 내용을 읽고 **확인하고 적용**을 누릅니다. 결과는 다른 기기에도 동기화됩니다. 검토 중 파일이 바뀌었다면 목록을 새로고침해 다시 비교하세요.

다른 기기의 삭제와 기존 첨부파일 교체도 검토를 기다립니다. **삭제 적용**을 확인하면 다른 기기에도 삭제가 반영될 수 있으며, 이 기기에서만 정리하는 기능이 아닙니다.

이전 파일이나 불완전한 파일을 복구하려면 **도움말 · 복구 → 복구 사본 → 사본 보기 → 별도 파일로 복구**를 사용하세요. 현재 파일은 그대로 두고 **Helenite Recovered** 폴더에 새 파일을 만듭니다. 복구한 파일은 다음 동기화에 포함됩니다. 내용을 확인한 뒤 필요한 부분을 원래 위치로 옮기세요.

저장이 중단됐다면 먼저 별도 사본으로 복구해 확인합니다. **현재 파일 유지/현재 상태 유지**는 현재 내용을 점검한 뒤에만 선택하세요. 일부만 저장된 파일이나 파일이 없는 상태를 동기화할 정상 상태로 받아들일 수 있습니다. 확인을 마칠 때까지 복구 사본을 남겨 두세요.

동기화와 복구 사본은 독립적인 백업을 대신하지 않습니다. 복구에 필요한 Helenite의 비공개 설정을 포함해 보관함을 별도의 안전한 위치에 백업하세요. 숨겨진 Helenite 상태를 임의로 지우지 말고, 연결 키가 들어 있는 `.obsidian/plugins/helenite/data.json`을 공유하지 마세요. 이메일 로그인으로 분실한 암호화 키를 되찾을 수는 없습니다.

## 계정 또는 PC 복구

- **같은 PC의 권한이 해제된 경우:** **PC 등록 상태 확인**을 누르고, 제공되는 경우 **계정 다시 확인 → PC 등록 복구**를 진행합니다. 로그인만으로 해제가 취소되지는 않으며, PC에 저장된 기존 인증정보가 필요합니다.
- **PC를 분실하거나 교체한 경우:** 등록 중 다른 PC가 있다는 안내가 나오면 **이전 PC를 이 PC로 교체**를 사용합니다. 최근 이메일 코드 로그인과 별도 확인이 필요합니다. 연결 권한을 옮길 뿐 노트나 암호화 키를 복원하지 않으므로 살아 있는 보관함 사본과 연결된 기기가 필요합니다. 남은 사본을 지우고 다시 시작하지 마세요.
- **결제 대기/검토가 필요한 경우:** 문제를 없애려고 다시 결제하지 마세요. 화면 상태를 보존하고 시험을 안내한 담당자/경로에 문의하세요. 이 초안 시점에는 일반 고객 지원과 운영 결제 복구가 아직 제공되지 않습니다.

Helenite 다운로드·설치는 무료이며, 동기화에는 구독 또는 명시적으로 제공한 체험 자격이 필요합니다. 계획한 가격은 월 USD 3 또는 연 USD 24입니다. 만료 후에도 이미 저장한 로컬 노트는 열람·복사·반출할 수 있습니다. 개발용 로컬 시험 모드는 영구 무료 동기화 요금제가 아닙니다.

공개 결제 후 일반 해지는 다음 갱신을 중단하고 결제한 기간은 유지합니다. 최종 서비스·환불·중계 포함량 조건은 결제 개시 전에 공개되어야 하며, 이 안내문은 결제 약관이 아닙니다. 최종 배포본의 구독 자격 적용 검증은 남아 있습니다.

## 업데이트와 문의 준비

Egress가 지정한 고객·개인정보 문의 주소는 **admin@egress.llc**입니다. 초대 시험 중에는 시험 담당자의 안내도 따르세요. 이 초안으로 응답 시간이나 일반 고객 지원 개시를 보증하지 않습니다.

데스크톱의 **연결 도움말**에서 **Helenite 업데이트**를 볼 수 있습니다. 검증된 공개 업데이트가 제공되면 **업데이트 확인 → 업데이트 내려받기 → 설치 파일 열기**로 진행합니다. 사용자가 설치를 시작하며 자동 무인 설치나 자동 되돌리기를 제공하지 않습니다. 현재 공개 피드는 아직 없으므로 확인 불가/실패가 최신 버전이라는 뜻은 아닙니다.

커뮤니티 등재 후에는 각 기기의 **설정 → 커뮤니티 플러그인**에서 플러그인을 업데이트합니다. 승인 전에는 시험 담당자의 업데이트 안내를 따르고 기존 연결 설정을 보존하세요. 데스크톱 앱과 플러그인 버전은 별개이며, 기능에 따라 연결된 모든 기기의 업데이트가 필요합니다.

문제가 생기면 했던 동작, 기기/OS, 발생 시각, 화면의 정확한 문구를 기록하세요. 데스크톱의 **연결 도움말 → 진단 정보 보기 → 진단 정보 복사**에서 미리보기를 확인한 후 시험 담당자에게 비공개 전달할 수 있습니다. 자동 업로드는 없습니다. 보고서에는 노트·보관함 이름/경로·계정 이메일·URL/IP·연결 비밀정보가 포함되지 않습니다. 휴대폰의 노트 수신을 증명하는 보고서는 아닙니다. 암호·이메일 코드·연결 링크·플러그인 `data.json`은 보내지 마세요.

## 현재 범위와 제한

| 항목 | 현재 기준 |
| --- | --- |
| 플러그인 호환 | Obsidian **1.7.2 이상**으로 선언되어 있습니다. 최소 버전과 최종 실기기 전체 검증은 남아 있습니다. |
| 파일 크기 | 승인된 모든 기기와 서버가 큰 파일을 지원하면 파일당 **64 MiB**까지입니다. 그렇지 않으면 **8 MiB** 호환 제한을 유지합니다. 초과 파일은 로컬에 남기고 전송을 보류합니다. |
| 텍스트 병합 | 자동 병합과 직접 검토할 텍스트는 **128 KiB**까지입니다. 겹치는 수정은 선택이 필요할 수 있습니다. |
| 저장 공간 | 각 기기에 노트·미전송 변경·복구 사본을 위한 공간이 필요합니다. 기기의 저장 공간과 중계 전송량은 별개입니다. |
| 중계 서비스 | 공개 판매용 포함량과 한도 도달 시 처리는 아직 확정되지 않았습니다. |
| 실행 조건 | 서버 PC는 깨어 있고 온라인이어야 하며 Helenite와 Obsidian을 함께 실행합니다. 휴대폰은 Obsidian을 화면에 엽니다. USB는 필요 없습니다. |
| 검증 범위 | Mac 서명, Linux 서명 패키지·VM 검증, Windows VM 검증이 일반 사용자 실기기 검증 완료를 뜻하지 않습니다. Windows 서명과 공개 출시는 준비 중입니다. |
