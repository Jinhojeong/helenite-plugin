# Security reporting

Please report suspected Helenite vulnerabilities privately to **admin@egress.llc**, operated by **Egress**. Do not file a public issue containing an exploit, private data or connection credentials.

Your initial report can include the affected component and version, operating system, a short description of the impact, and reproduction steps using disposable data. Do not send passwords, login codes, signing keys, access tokens, connection links or QRs, plugin `data.json`, or a private vault. Ask first if you need a secure way to provide sensitive evidence.

Helenite is currently under community review and pre-release validation. This policy does not declare any version production-accepted, promise a response deadline, or establish a bug bounty. We will coordinate follow-up and disclosure through the private conversation.

This file provides the email reporting route. It does not imply that GitHub's separate private vulnerability reporting feature is enabled.

보안 문제는 공개 이슈 대신 **admin@egress.llc**로 보내 주세요. 영향받는 구성요소·버전, 영향과 예시 데이터로 재현하는 방법을 간단히 알려 주세요. 암호·키·인증번호·QR·연결 링크·개인 보관함은 보내지 마세요.
